# IZ Recorder

Диктофон для Android (Pixel 8 Pro), который запускается кнопками громкости, не доставая
телефон, и сам расшифровывает запись в текст прямо на телефоне, без интернета
(английский и русский).

## Возможности

- **Запуск и остановка кнопками громкости.** N быстрых нажатий любой из кнопок (по умолчанию 5)
  включают запись, столько же нажатий её останавливают.
- **Вибро-подтверждение.** Начало — одна длинная вибрация (по умолчанию 3 с), конец — две
  вибрации, ошибка — три коротких. Длительность настраивается.
- **Автостоп** через заданное время (5 мин – 3 ч) или без ограничения.
- **Быстрая команда «зажать обе кнопки громкости».** Работает как дополнительный способ
  запуска, в том числе на экране блокировки.
- **Расшифровка на телефоне** через [whisper.cpp](https://github.com/ggml-org/whisper.cpp):
  язык определяется автоматически (EN/RU). У каждой фразы есть отметка времени: нажатие
  на фразу проигрывает это место. Скорость воспроизведения 0.5x–1.25x.
- **Два раздела:**
  - **Диктофон.** Ваши записи, никогда не удаляются.
  - **Входящие.** Аудио, которым вы поделились с приложением (например, голосовые из
    мессенджеров: «Поделиться» → IZ Recorder). Удаляются через 30 дней (срок настраивается).
    Нужное можно перенести в «Диктофон» кнопкой «Хранить всегда».

## Установка

1. Откройте на телефоне раздел **Releases** этого репозитория, скачайте последний
   `IZRecorder-N.apk` и установите (Android попросит разрешить установку из браузера).
2. Откройте приложение и разрешите микрофон и уведомления.
3. Включите службу «IZ Recorder — кнопки громкости»:
   Настройки → Спец. возможности → IZ Recorder — кнопки громкости.
   Если переключатель серый («Ограниченная настройка»): Настройки → Приложения →
   IZ Recorder → ⋮ → «Разрешить ограниченные настройки», затем повторите.
4. Скачайте модель распознавания (кнопка в приложении; Small ≈ 190 МБ, один раз).
5. Снимите ограничение батареи (кнопка в настройках приложения).

## Ограничения Android

- Пока идёт запись, система всегда показывает уведомление и зелёный индикатор
  микрофона. Скрыть их нельзя.
- Во время телефонного звонка другие приложения не получают звук с микрофона, поэтому
  запись звонков не поддерживается. Для звонков на Pixel есть «Live Caption»
  (субтитры во время разговора).
- Срабатывание кнопок громкости при **полностью выключенном экране** зависит от
  прошивки, это нужно проверить на своём телефоне.

## Сборка

APK собирается автоматически в GitHub Actions (`.github/workflows/android.yml`) на каждый push
и публикуется в Releases.

Чтобы обновления ставились поверх старой версии без потери записей, у всех сборок должна
быть одна подпись. Для постоянной подписи добавьте в Settings → Secrets → Actions:
`IZ_KEYSTORE_BASE64` (keystore в base64), `IZ_KEYSTORE_PASSWORD`, `IZ_KEY_ALIAS`,
`IZ_KEY_PASSWORD`. Без них используется debug-ключ, который хранится в кэше Actions.
Кэш может очиститься, если сборок не было больше недели.

Локально: `./gradlew assembleRelease` (нужны Android SDK и NDK).
